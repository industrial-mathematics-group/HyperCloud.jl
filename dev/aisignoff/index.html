AI signoff report

This package declares how AI was used to write it, file by file and, from the git history, line by line, on three axes:

  • Generation (G0 to G3): from written by a person (G0) to AI-autonomous (G3).
  • Human review (H0 to H3): from a plausibility check (H0) to independently validated (H3).
  • AI review (A0 to A3): from no independent AI review (A0) to validated by a different model (A3).

The declarations are in SIGNOFF.toml and in the descriptions of the merged pull requests, and aisignoff checks them on every pull request. The levels are defined in the aisignoff documentation.

The report below was generated from the commit these pages were built from. Click a folder in the sunburst to zoom in, and a file to see the level of each line.

Open the report on its own page, where it has more room.

Building the docs locally

The report is generated by the docs workflow and is not in the repository. To include it in a local build, run pipx run --spec aisignoff==1.0.0rc8 aisignoff report --html docs/src/assets/aisignoff.html --with-source in the repository before docs/make.jl (with the whole git history, for the line-by-line declarations).
