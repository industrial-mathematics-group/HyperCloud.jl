BGK Equation

BGKEquation is a discrete-velocity model of the Bhatnagar–Gross–Krook equation

\[\partial_t f + \vec v\cdot\nabla_x f = \frac{1}{\tau}\big(\mathcal M[f] - f\big),\]

for the distribution $f(\vec x, \vec v, t)$ of a gas in $D$ space dimensions. Its moments $U = (\rho, \rho\vec u, E)$ are the conservative variables of the Euler equations, which the BGK solution approaches for $\tau \to 0$; for $\tau \to \infty$ every velocity moves freely.

Velocity space as the state vector

The velocity space is discretised by a tensor grid of Nv nodes per direction (velocity_grid), and the particle state is the vector of distribution values at the nodes: the number of equations is the number of discrete velocities. Everything HyperCloudCore offers (MUSCL, limiters, MOOD, IMEX, moving grids, the device backends) therefore runs on the BGK model unchanged. On a moving grid the Rusanov flux of the frame (ALEFrame, LagrangianFrame) keeps the per-velocity upwind dissipation, |v_k − w| per component (the generic Rusanov of the frame dissipated every velocity with the largest relative speed and smeared the contact of the Sod on Lagrangian particles). Moments are quadrature sums, $U = \sum_k w_k\,(1, \vec v_k, \tfrac12|\vec v_k|^2)\,f_k$.

Since the state is an SVector, its length drives compile time and per-particle cost. The model keeps it small in three ways:

  • Only D velocity directions. Degrees of freedom beyond the resolved velocity directions (the remaining directions of a 3-D gas and internal ones, $K = 2/(\gamma - 1) - D$ in total) are carried by a second distribution $h = \int \tfrac12|\xi|^2 f\,d\xi$ on the same nodes (a Chu reduction). The state is $f$ for $\gamma = (D + 2)/D$ ($M = N_v^D$), otherwise $(f, h)$ ($M = 2 N_v^D$). A 1-D shock tube with $\gamma = 1.4$ needs a 1-D velocity grid, not $N_v^3$ velocities.
  • Gauss–Hermite nodes (:velocity_grid => :gauss_hermite) integrate polynomials times the Gaussian of their scale exactly, so near-equilibrium flows need far fewer nodes than the uniform midpoint grid (:uniform, the robust choice for strongly non-equilibrium flows).
  • No per-velocity arrays in kernels. The equation is a small bits type (1-D nodes and weights, grid centre, $K$, $\gamma$, relaxation model); the node of a component is resolved from its index at compile time, so the flux and the dissipation unroll into straight-line code.

Collision term

The equilibrium is the conservative discrete Maxwellian of equilibrium ($f_k = \exp(\alpha\cdot\psi_k)$ with $\psi = (1, \vec v, \tfrac12|\vec v|^2)$, Mieussens' discrete entropic equilibrium, $h_k = \tfrac K2\,\hat\theta f_k$): $\alpha$ is found by a damped Newton iteration on the convex dual problem, started from the continuous Maxwellian, so the discrete moments of the equilibrium equal $U$ to round-off and the collision term conserves mass, momentum and energy exactly. A few microseconds per particle; the iteration runs inside the kernels.

The relaxation time comes from a RelaxationTimeModel: constant (ConstantRelaxationTime, Inf for free transport) or $\tau = \mu(\theta)/p$ with a power-law viscosity (ViscosityRelaxationTime).

With an IMEX tableau the collision is the implicit source BGKRelaxation. Because it conserves the moments, the implicit stage equation has the closed-form solution $f = (f^* + \lambda\,\mathcal M[f^*])/(1 + \lambda)$, $\lambda = \Delta t\,a_{ii}/\tau$, for any stiffness, which makes the scheme asymptotic preserving: at $\tau = 10^{-5}$ the BGK Sod solution is as close to the exact Euler solution as the Euler scheme itself, and $\tau = 0$ ($\lambda = \infty$) gives $\mathcal M[f^*]$. With an explicit tableau the collision becomes ExplicitBGKRelaxation (stable for $\Delta t \lesssim \tau$ only; $\tau = 0$ is rejected with an ArgumentError). Negative relaxation times are rejected when the equation is built.

Transport

The flux is $v_{k,d} f_k$. The transport is linear and diagonal, so the Rusanov flux of every velocity is its exact upwind flux: RusanovFlux, UpwindFlux and AlignedRusanovFlux use the dissipation $|v_{k,d}|$ per component instead of the largest node speed for all components (which smears the slow velocities; on a smooth collisionless wave it costs a factor 2 to 10 in the error). max_eigenvalue is the largest node speed, which sets the CFL time step.

The PAD of MOOD (is_admissible) asks for positive density and temperature; individual $f_k$ may dip below zero.

Configuration

:PDE_name => :bgk, :PDE_D => 1, :PDE_gamma => 1.4,
:PDE_Nv => 24, :PDE_vmax => 6.0, :PDE_velocity_grid => :uniform,
:PDE_tau => 1e-3,                       # or :PDE_viscosity => μ_ref, :PDE_omega => ω
:sim_func_name => :run_bgk_simulation,  # direct and kinetic runners forward BGK runs here

Initial conditions give the macroscopic state $(\rho, \rho\vec u, E)$, exactly as for an Euler run with the same $\gamma$; every particle starts in the discrete Maxwellian of that state. The stored snapshots are the moments, so BGK and Euler runs can be compared directly (:save_relax => true keeps the distributions). Choose vmax so that the Maxwellians of the flow decay inside the grid ($|u| + 5\sqrt\theta$ or more) and enough nodes to resolve them ($\Delta v \lesssim \sqrt\theta$).

References: the collisionless model has the exact solution of analytic_closure (each velocity transported, initial data in equilibrium); for small $\tau$ use euler_limit_solution as the reference of a SimulationConfig (see the example bgk_1d_sod).

The cost per particle grows linearly with $M$ up to a few hundred equations. Walls

diffuse_wall(θ_w; velocity, accommodation) is the Maxwell (diffuse) wall, slip_wall() the specular one, both operators of MirrorBC; see Walls and Moving Boundaries. A gas in equilibrium at the wall temperature is reflected into itself exactly.

Block form for large velocity grids

Beyond a few hundred components the SVector state is too large (see the cost table and HyperCloudCore's "Block States" page). BGKBlocks(eq, Val(W)) is the same BGK model as a block equation of HyperCloudCore's block pipeline: the M components of the state of eq (the f values, then the h values of the Chu reduction) split into M / W blocks of W consecutive components, each transported on its own with the per-velocity upwind dissipation of its velocities, and the collision couples them through the moments. BGKBlockRelaxation is the collision term in two passes: the reduction over the blocks of a particle gives the moments, the relaxation time and the exponential parameters $\alpha$ of the conservative discrete Maxwellian (equilibrium_parameters); the update of a block then evaluates the Maxwellian component by component (equilibrium_component), f = (f* + λ M) / (1 + λ) as for the single state. Nothing of length M is ever built. A block run reproduces the SVector run (BGKRelaxation, same scheme and tableau) to round-off.

eq  = BGKEquation(Val(1), nodes, weights, 1.4, ConstantRelaxationTime(1e-3))    # M = 2 Nv
bk  = BGKBlocks(eq, Val(8))                                                    # blocks of 8 components
pg  = ParticleGrid(geom, (dx,), weight, 8)
bs  = BlockState(bk, pg)
set_block_states!((x, b) -> equilibrium_block(bk, U0(x), b), bs, pg)          # the Maxwellian of the macroscopic IC
ts  = BlockTimeStepper(bk, MUSCL(Float64, 1, 8, 2, VenkatakrishnanLimiter(:hard), RusanovFlux()),
                       (BlockSourceTerm(BGKBlockRelaxation(bk)),), IMEX_ARS222_Tableau(Float64))
ts(bk, pg, bs, t, dt)
U = block_moments(bk, bs, i)                                                   # (ρ, ρu, E) of particle i

From a configuration, :PDE_block_width => W runs the block form through run_bgk_simulation (also for a mixture, MixtureBlocks with MixtureBlockRelaxation: W must divide every species' state length; :PDE_blocks_per_launch sets how many blocks one launch of the scheme's pre-pass and flux pass covers, HyperCloudCore's blocks_per_launch, the scratch of those passes being replicated that many times; MUSCL streams its divergence there unless :Scheme_streamed => false, see Configuration); the snapshots hold the macroscopic moments; :PDE_devices splits the blocks over the GPUs of one node, every device holding the whole cloud and a range of blocks and the devices exchanging the moments of their blocks per stage (the collision's parameters, the frame velocity, the admissibility; the kinetic walls' ghost rows), see HyperCloudCore's BlockDevices; :save_relax is refused, MOOD works with every criterion (the admissibility across the blocks is the positivity of the moments), a moving grid runs in the ALE frame with the mean velocity of the moments as the particle velocity (the Lagrangian movers; the conservative Lagrangian frame of the single state has no block form), and the kinetic walls act in two passes (the zero-flux density of a diffuse wall from all velocities; the specular reflection as the exact node flip where it applies and as the reflection off the node grid otherwise, as on the single state). Moving boundary pieces (a piston) and the particle adaptivity work on every block; the storage follows the backend (the parameter arrays of the collision included), and set_memory_limit! reserves the block stepper and the block state (the state arrays count nb elements per particle). The collision's reduction is given in the additive form of HyperCloudCore's block_partial (the moments of a block range), which a block state split over devices exchanges.

Gas mixtures

BGKMixture is the discrete-velocity model of a mixture of $L$ species with the multi-species BGK operator of Bobylev, Bisi, Groppi, Spiga and Potapenko (BBGSP),

\[\partial_t f_s + \vec v\cdot\nabla_x f_s = \frac{1}{\varepsilon}\,\nu_{ss}\,(n_s M_{ss} - f_s) + \frac{1}{\kappa}\sum_{r\ne s}\nu_{sr}\,(n_s M_{sr} - f_s), \qquad s = 1,\dots,L,\]

with the number densities $n_s$, the collision frequencies $\nu_{sr} = \lambda_{sr} n_r$ (a symmetric matrix of constants $\lambda$: Maxwell molecules), the intra-species Knudsen number $\varepsilon$ and the inter-species one $\kappa$. $M_{sr}$ is the unit-density Maxwellian of species $s$ (mass $m_s$) at the mixture velocity $\vec U_{sr} = (1 - a_{sr})\vec U_s + a_{sr}\vec U_r$ and temperature $T_{sr} = (1 - b_{sr}) T_s + b_{sr} T_r + \gamma_{sr}|\vec U_s - \vec U_r|^2/k_B$ with $a_{sr} = m_r/(m_s + m_r)$, $b_{sr} = 2 a_{sr} m_s/(m_s + m_r)$ and $\gamma_{sr} = m_s a_{sr}^2/n_{\mathrm{dof}}$ ($n_{\mathrm{dof}} = D + K$, 3 for a monatomic gas): the choice for which the operator conserves every species' number density and the total momentum and energy.

  • One state, species blocks. Every species is a BGKEquation on its own velocity grid (a light species needs a wider one; the Chu reduction and the node tables are per species), with the thermal speed $\theta_s = k_B T_s/m_s$ as its temperature. The particle state is the concatenation of the species' states, $M = \sum_s M_s$, and the transport stays diagonal, so the flux, the per-velocity Rusanov dissipation (static and in the moving frames, which move with the mass-averaged mixture velocity), MOOD and the walls (slip_wall() species by species, diffuse_wall(T_w) at the thermodynamic wall temperature, emitting species $s$ at $k_B T_w/m_s$) carry over from the single gas. The macroscopic state of moments is the species' number moments $(n_s, n_s\vec u_s, e_s)$ one after the other ($L(D + 2)$ numbers; mixture_state builds it from $n_s$, $\vec u_s$, $T_s$, species_primitives reads it back, mixture_moments gives $(\rho, \rho\vec U, E)$).
  • Collision step. MixtureRelaxation solves the implicit stage equation in closed form, as the relaxation step of the paper: the species densities are invariant, so $\nu_{sr}$ is known; the species velocities and temperatures after the stage come from two $L \times L$ symmetric positive definite systems (the graph Laplacians of $d_{sr} = \lambda_{sr} n_s n_r m_s m_r/(m_s + m_r)$ and of $c_{sr} = n_{\mathrm{dof}} k_B \lambda_{sr} n_s n_r m_s m_r/(m_s + m_r)^2$, the latter with the exchanged kinetic energy on the right-hand side), which conserve the totals exactly; the Maxwellians are then the conservative discrete equilibria of each species at those values (discrete moments exact, so the moment correction of the paper is not needed), and $f_s = (f_s^* + \Delta t\,a_{ii}\sum_r (\nu_{sr}/\varepsilon_{sr})\,n_s M_{sr}) / (1 + \Delta t\,a_{ii}\sum_r \nu_{sr}/\varepsilon_{sr})$. Exact for any stiffness in $\varepsilon$ and $\kappa$ (asymptotic preserving); with an explicit tableau ExplicitMixtureRelaxation. Checked: the species densities, total momentum and energy are kept to round-off per step and over a periodic run; a one-species mixture reproduces BGKRelaxation with $\tau = \varepsilon/(\lambda n)$ to round-off, and two identical species with equal states are the two halves of that single gas (also over a run, with $\tau = \mu/\rho$, $\mu = \varepsilon/\lambda$).
  • Units. $m_s$, $k_B$ and $\lambda$ are plain numbers. Dimensionless problems use $k_B = 1$; with the molar masses in g/mol as $m_s$ and $k_B = R = 8.3145$ temperatures are in kelvin and velocities in units of $\sqrt{1000}\,\mathrm{m/s} \approx 31.6\,\mathrm{m/s}$ (He–Ar: $\lambda_{11} = 19.96$, $\lambda_{12} = 1.153$, $\lambda_{22} = 17.52$).
:PDE_name => :bgk_mixture, :PDE_D => 1,
:PDE_masses => (4.0, 40.0), :PDE_lambda => [19.96 1.153; 1.153 17.52], :PDE_kB => 8.3145,
:PDE_epsilon => 1e-3, :PDE_kappa => 1e-3,
:PDE_Nv => 30, :PDE_vmax => (125.0, 60.0),       # one velocity grid per species
:sim_func_name => :run_bgk_simulation,

Initial conditions give the species' number moments, e.g. :IC_uL => Tuple(mixture_state(eq, n, u, T)); the stored snapshots are the species' number moments. The state length grows with the number of species and their grids (two species with 30² nodes and the Chu reduction are 3600 components per particle, far beyond the table above): start with 1-D problems and measure.

API

HyperCloud.BGKEquation — Type
BGKEquation{D, M, T, NV1, NV, R} <: HyperbolicPDE{D, M, T}
BGKEquation(::Val{D}, nodes, weights, gamma, relaxation; center = 0)

Discrete-velocity model of the BGK equation ∂_t f + v·∇f = (M[f] - f) / τ in D space dimensions. The velocity space is the tensor product of the 1-D nodes (with quadrature weights, see velocity_grid) in every direction, shifted by center: NV = NV1^D discrete velocities.

The state of a particle is the vector of distribution values at the nodes, so the number of equations is the number of velocities. Degrees of freedom beyond the D resolved velocity directions (the remaining velocity directions of a 3-D gas and internal ones, K = 2 / (γ - 1) - D in total) are carried by a second distribution h (a Chu reduction, h = ∫ |ξ|²/2 f dξ over the unresolved directions): for K = 0 (γ = (D + 2) / D) the state is f (M = NV), otherwise (f, h) (M = 2 NV). Any γ thus needs only a D-dimensional velocity grid.

The macroscopic state is U = (ρ, ρu..., E) = Σ_k w_k (1, v_k, |v_k|²/2) f_k + (0, 0, h_k) (see moments), the conservative variables of the Euler equations with the same γ (euler_limit), which the BGK solution approaches for τ → 0. The collision term relaxes towards the conservative discrete Maxwellian of equilibrium (source terms BGKRelaxation, ExplicitBGKRelaxation) with the relaxation time of relaxation (a RelaxationTimeModel).

The transport is linear and diagonal (velocity k moves with v_k): the flux is v_{k,d} f_k, the Rusanov and Upwind fluxes reduce to exact upwinding per velocity (dissipation |v_{k,d}| instead of the largest speed for every component), and max_eigenvalue is the largest node speed. The equation object is a small bits type (nodes, weights, center, K, γ, the relaxation model); node indices are resolved at compile time, so there are no per-velocity arrays in the kernels.

HyperCloud.velocity_grid — Function
velocity_grid(kind::Symbol, Nv::Int, vmax::Real, ::Type{T} = Float64) -> (nodes, weights)

One-dimensional velocity nodes and quadrature weights (SVector{Nv, T} each) of a discrete-velocity model; the BGK equation uses their tensor product in every spatial direction.

  • :uniform: midpoint rule on [-vmax, vmax], v_j = -vmax + (j - 1/2) Δv, weights Δv = 2 vmax / Nv. Spectrally accurate for Maxwellians that decay inside the interval; the robust choice for strongly non-equilibrium flows.
  • :gauss_hermite: Gauss–Hermite nodes scaled so that the outermost node is ±vmax, with the weights w_j e^{x_j^2} that integrate f itself. Exact for polynomials times the Gaussian of that scale, so near-equilibrium flows need far fewer nodes (the conservative equilibrium keeps the moments exact either way). Weights come from the Christoffel function of the Hermite functions (stable for large Nv).

HyperCloud.equilibrium — Function
equilibrium(eq::BGKEquation, U::State{D + 2}) -> (f_eq::State{M}, ok::Bool)

Conservative discrete Maxwellian of the macroscopic state U = (ρ, ρu..., E): the discrete entropic equilibrium f_k = exp(α·ψ_k) (Mieussens), whose discrete moments reproduce U to round-off on the velocity grid, so the collision term conserves mass, momentum and energy exactly. α is found by a damped Newton iteration on the convex dual problem, started from the continuous Maxwellian (on a grid that resolves the Maxwellian that start is already accurate to the quadrature error, so one or two iterations suffice). With internal degrees of freedom h_k = (K/2) θ̂ f_k.

ok is false for a non-physical U (non-finite, ρ ≤ 0 or θ ≤ 0); f_eq is meaningless then. If the grid cannot represent U (e.g. a mean velocity near vmax), the iteration stops at the closest equilibrium it reaches. Allocation free, runs inside kernels. equilibrium_parameters gives α alone and equilibrium_component one component of the equilibrium from it (the block pipeline never builds the whole state).

HyperCloud.ConstantRelaxationTime — Type
ConstantRelaxationTime(tau)

Constant relaxation time τ ≥ 0 (the Knudsen number of the non-dimensional BGK equation). τ = Inf is the collisionless (free transport) limit: the runners drop the collision term and analytic_closure returns the exact solution of the discrete-velocity model. τ = 0 projects onto the equilibrium in every implicit stage (IMEX tableaus only); BGKEquation rejects τ < 0.

HyperCloud.ViscosityRelaxationTime — Type
ViscosityRelaxationTime(mu_ref, omega)

τ = μ(θ) / p with the power-law viscosity μ = mu_ref θ^ω (the Chapman–Enskog viscosity of the BGK model is τ p), i.e. τ = mu_ref θ^(ω - 1) / ρ. ω = 1/2 are hard spheres, ω = 1 Maxwell molecules.

HyperCloud.BGKRelaxation — Type
BGKRelaxation(eq::BGKEquation) <: AbstractImplicitSourceTerm
ExplicitBGKRelaxation(eq::BGKEquation) <: AbstractExplicitSourceTerm

The BGK collision term S(f) = (M[f] - f) / τ with the conservative discrete Maxwellian M[f] of equilibrium and τ from the equation's RelaxationTimeModel, treated implicitly (IMEX tableaus) or explicitly (explicit RK tableaus, only stable for Δt ≲ τ).

The implicit stage equation f = f* + Δt a_ii S(f) is solved in closed form: the collision conserves the moments, so M[f] = M[f*] and τ(f) = τ(f*), and f = (f* + λ M[f*]) / (1 + λ) with λ = Δt a_ii / τ. This is exact for any stiffness (τ → 0 projects onto the equilibrium, and τ = 0, i.e. λ = Inf, returns M[f*]), which makes the IMEX scheme asymptotic preserving towards the Euler equations. The explicit form divides by τ, so bgk_sources rejects τ = 0 for explicit tableaus. A non-physical particle state (ρ ≤ 0 or θ ≤ 0) is left untouched (zero source).

HyperCloud.BGKBlocks — Type
BGKBlocks(eq::BGKEquation, ::Val{W}) <: HyperbolicPDE{D, W, T}

The BGK model of eq as a block equation of HyperCloudCore's block pipeline (BlockState, BlockTimeStepper): the M components of the state of eq (the f values at the velocity nodes, then the h values of the Chu reduction) split into M / W blocks of W consecutive components; block b holds the components (b − 1) W + 1 … b W. The equation object is eq itself (its small node tables); only the state is distributed, so the state length M can be thousands of components without compiling anything of that size. block_moments reduces the moments of a particle from a BlockState, equilibrium_block gives one block of the discrete Maxwellian of a macroscopic state (initial conditions).

HyperCloud.MixtureBlocks — Type
MixtureBlocks(mix::BGKMixture, ::Val{W}) <: HyperbolicPDE{D, W, T}

The mixture of BGKMixture as a block equation of HyperCloudCore's block pipeline: the state of every species (M_s components, f then the Chu h) splits into M_s / W blocks of W consecutive components, the blocks of species 1 first; W must divide every M_s, so no block straddles two species. species_of_block maps a block to its species and its position there. Transport is per block with the per-velocity upwind dissipation of the block's velocities; the collision (MixtureBlockRelaxation) couples all blocks through the species' moments. block_moments reduces the species' number moments (the macroscopic state of moments) from a BlockState.

HyperCloud.BGKMixture — Type
BGKMixture{D, M, T, L, S, LL} <: DiscreteVelocityEquation{D, M, T}
BGKMixture(species::NTuple{L, BGKEquation}, masses, lambda; epsilon = 1, kappa = epsilon, kB = 1)
BGKMixture(::Val{D}, masses, lambda, grids; gamma = 5/3, epsilon = 1, kappa = epsilon, kB = 1, centers = nothing)

Discrete-velocity model of a gas mixture of L species with the multi-species BGK collision operator of Bobylev, Bisi, Groppi, Spiga and Potapenko (BBGSP),

∂_t f_s + v·∇f_s = (1/ε) ν_ss (n_s M_ss − f_s) + (1/κ) Σ_{r≠s} ν_sr (n_s M_sr − f_s),   s = 1 … L,

with the species number densities n_s = ∫ f_s dv, the collision frequencies ν_sr = λ_sr n_r (λ a symmetric matrix of constants: Maxwell molecules), the intra-species Knudsen number ε and the inter-species one κ, and the unit-density Maxwellians M_sr of species s (mass m_s) at the mixture velocity and temperature

U_sr = (1 − a_sr) U_s + a_sr U_r,     T_sr = (1 − b_sr) T_s + b_sr T_r + γ_sr / k_B |U_s − U_r|²,
a_sr = m_r / (m_s + m_r),   b_sr = 2 a_sr m_s / (m_s + m_r),   γ_sr = m_s a_sr² / n_dof,

(n_dof = D + K the number of translational degrees of freedom, 3 for a monatomic gas), the choice for which the operator conserves every species number density and the total momentum and energy (MixtureRelaxation). M_ss is the Maxwellian of species s itself.

Every species s is a BGKEquation on its own velocity grid (nodes, weights, centre and the Chu reduction h for the unresolved degrees of freedom; its relaxation model is ignored, the mixture's λ, ε, κ define the collisions), with the thermal speed θ_s = k_B T_s / m_s as its temperature. The state of a particle is the concatenation of the species' states (M = Σ_s M_s components); the transport is diagonal, so the flux, the per-velocity Rusanov dissipation (also in the ALEFrame and LagrangianFrame of a moving grid, with the mass-averaged mixture velocity as the fluid velocity), MOOD and the walls (SlipWall per species, DiffuseWall at the thermodynamic wall temperature, emitting every species at k_B T_w / m_s) carry over from the single gas.

Units: m_s, k_B and λ are plain numbers. Dimensionless problems use k_B = 1; with the molar masses M_s (g/mol) as m_s and k_B = R = 8.3145 (J/(mol K)) temperatures are in kelvin and velocities in units of √1000 m/s ≈ 31.6 m/s. ε and κ must be positive (Inf switches that part of the collision off; every λ_sr = 0 or ε = κ = Inf is collisionless). All species need the same D, element type and K.

The convenience constructor takes one (nodes, weights) pair per species (from velocity_grid; the grids may differ, a light species needs a wider one) and a common gamma (default 5/3, monatomic; K = 2/(γ − 1) − D unresolved degrees of freedom per species), optionally centers (one tuple per species).

The macroscopic state of moments is the concatenation of the species' number moments (n_s, n_s u_s…, e_s) with e_s = n_s (n_dof/2 θ_s + |u_s|²/2) (the Euler state of species s per unit mass), L (D + 2) numbers: what an initial condition returns (mixture_state builds it from n_s, u_s, T_s), species_primitives turns it back into (n_s, u_s, T_s), and mixture_moments gives the mass-weighted mixture state (ρ, ρU, E).

HyperCloud.MixtureRelaxation — Type
MixtureRelaxation(eq::BGKMixture) <: AbstractImplicitSourceTerm
ExplicitMixtureRelaxation(eq::BGKMixture) <: AbstractExplicitSourceTerm

The BBGSP collision operator of a BGKMixture, Q_s = (1/ε) ν_ss (n_s M_ss − f_s) + (1/κ) Σ_{r≠s} ν_sr (n_s M_sr − f_s), treated implicitly (IMEX tableaus) or explicitly (explicit tableaus, stable for Δt ≲ ε/ν only).

The implicit stage equation f = f* + Δt a_ii Q(f) is solved in closed form, species by species, as in the paper's relaxation step: the collision conserves the species number densities, so n_s and the frequencies ν_sr = λ_sr n_r are known from f*; the species velocities and temperatures after the stage follow from two L × L symmetric positive definite systems (one per velocity component, the graph Laplacian of the weights d_sr = λ_sr n_s n_r m_s m_r / (m_s + m_r), and one for the temperatures with c_sr = n_dof k_B λ_sr n_s n_r m_s m_r / (m_s + m_r)², whose right-hand side holds the kinetic energy exchanged), which conserve the total momentum and energy exactly. The Maxwellians M_ss, M_sr are then built at those values with the conservative discrete equilibrium of each species (discrete moments exact to round-off, so no moment correction is needed), and f_s = (f_s* + Δt a_ii Σ_r (ν_sr/ε_sr) n_s M_sr) / (1 + Δt a_ii Σ_r ν_sr/ε_sr) with ε_ss = ε, ε_sr = κ. Exact for any stiffness in ε and κ (asymptotic preserving). A particle whose state is not physical (a species with n_s ≤ 0 or T_s ≤ 0, or an equilibrium the grid cannot represent) is left untouched (zero source).

HyperCloud.run_bgk_simulation — Function
run_bgk_simulation(params::ParamDict) -> Union{AbstractSimData, Nothing}

Runs the discrete-velocity BGK model (:PDE_name => :bgk, see BGKEquation) or a gas mixture (:PDE_name => :bgk_mixture, BGKMixture). The particle state is the distribution at the velocity nodes; the IC namespace gives the macroscopic state (ρ, ρu..., E) (initial conditions are built with M = D + 2, like an Euler run with the same γ; for a mixture the species' number moments (n_s, n_s u_s..., e_s), M = L (D + 2), see mixture_state), and every particle starts in its discrete Maxwellian. The collision term is implicit for an IMEX tableau (BGKRelaxation), explicit for an explicit one (ExplicitBGKRelaxation) and dropped in the collisionless limit (:PDE_tau => Inf). Schemes, fluxes, limiters, MOOD and the grid are configured exactly as for the other equations.

The returned snapshots hold the macroscopic moments (ρ, ρu..., E), directly comparable with Euler runs (for a mixture the species' number moments, see species_primitives); with :save_relax => true (or :Kinetic_save_relax => true, as for run_kinetic_simulation) they keep the full distributions instead. run_direct_simulation and run_kinetic_simulation forward BGK configurations here, so the method dictionaries work unchanged.
