# AI signoff report

This package declares how AI was used to write it, file by file and, from the git history, line by line, on three axes:

- **Generation** (G0 to G3): from written by a person (G0) to AI-autonomous (G3).
- **Human review** (H0 to H3): from a plausibility check (H0) to independently validated (H3).
- **AI review** (A0 to A3): from no independent AI review (A0) to validated by a different model (A3).

Reports also show the **findings** (F0 to F3) of the last independent AI review of each line: the highest
severity it left open, from none or trivial (F0) to critical (F3), and F- where no such review has covered the
line since it last changed.

The declarations are in `SIGNOFF.toml` and in the descriptions of the merged pull requests, and
[aisignoff](https://industrial-mathematics-group.github.io/aisignoff/) checks them on every pull request. The levels
are defined in the [aisignoff documentation](https://industrial-mathematics-group.github.io/aisignoff/levels/).

in, and a file to see the level of each line.

!!! note "Building the docs locally"
    The report is generated by the docs workflow and is not in the repository. To include it in a local build, run
    `pipx run --spec aisignoff==0.20.1 aisignoff report --html docs/src/assets/aisignoff.html --with-source` in the repository before
    `docs/make.jl` (with the whole git history, for the line-by-line declarations).
